# Kododo.MonitorWay.Core

Core model of [MonitorWay](https://github.com/kododo-dev/MonitorWay): `LogEntry`, `TraceEntry` and `TraceSpan`, `ErrorGroup`, `MetricInstrument`, and the queries over them. Applications use [Kododo.MonitorWay](https://www.nuget.org/packages/Kododo.MonitorWay) instead; this package is a dependency of it.
